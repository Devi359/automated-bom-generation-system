   Automated Bill of Materials Generation System using Onshape API

 Project Overview

The Automated Bill of Materials Generation System is a software solution designed to automatically extract assembly and part information from Onshape CAD models using the Onshape REST API and generate a structured Bill of Materials (BOM).

The system reduces manual BOM preparation, improves data accuracy, and provides a structured output for engineering and manufacturing applications.

 Objectives

- Automate Bill of Materials generation from CAD assembly data
- Extract part and assembly information using Onshape API
- Process and organize CAD data automatically
- Identify parent-child relationships between components
- Remove duplicate component information
- Generate a structured BOM output
